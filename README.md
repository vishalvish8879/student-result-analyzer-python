# Student Result Analyzer 📊

A beginner-friendly Python Data Analysis project built using **Pandas**, **Matplotlib**, and **Seaborn**.

## Features

- Read student data from CSV
- Calculate Total Marks
- Calculate Percentage
- Calculate Average Marks
- Assign Grades
- Pass/Fail Status
- Attendance Status
- Export Final Report to CSV
- Subject-wise Average Bar Chart
- Percentage Distribution Histogram
- Grade Distribution Pie Chart
- Correlation Heatmap

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Dataset

The project uses a custom student dataset containing:

- Student ID
- Name
- Maths
- Science
- English
- Computer
- Attendance
